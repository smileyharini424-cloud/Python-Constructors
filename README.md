# Python Constructors

## Explanation

A constructor is a special method that is automatically called when an object is created. In Python, the constructor is commonly defined using the `__init__()` method.

This program demonstrates how constructors initialize the attributes of different student objects.

## Problem Statement

Write a Python program to create a `Student` class with a constructor that initializes the student's name, age, and course. Create multiple objects and display their details.

## Features

* Demonstrates the `__init__()` constructor
* Initializes object attributes
* Creates multiple objects
* Uses instance attributes
* Displays student details

## How It Works

1. A `Student` class is created.
2. The `__init__()` method receives student details.
3. The details are stored as instance attributes.
4. Objects are created with different values.
5. The constructor automatically runs for each object.
6. Student details are displayed using a method.

Start → Define Class → Define Constructor → Create Objects → Initialize Attributes → Display Details → End
